Справочная информация

Подробное описание функций, терминов и возможностей системы.

Форма ввода IP.

Source IP Поле ввода исходящего ip-адреса или сети.
Данное поле принимает информацию об искомом исходящем/src ip-адресе. Поддерживается поиcк сети в формате "x.x.x.x/y". Пустое поле выполняет поиск любого совпадения/any ip.
Destination IP Поле ввода входящего ip-адреса или сети.
Данное поле принимает информацию об искомом входящем/dst ip-адресе. Поддерживается поиcк сети в формате "x.x.x.x/y". Пустое поле выполняет поиск любого совпадения/any ip.
Строгое соответствие Чекбокс строго поиска ip-адреса.
Позволяет выполнять строгий поиск ip-адреса минуя любые его вхождения в сети. Поиск сети "net/mask" всегда выполняется строго.
Source or Destination Чекбокс прямого и обратного поиска.
Позволяет выполнять поиск ip-адреса/сети минуя в прямом и обратном порядке направления трафика: "src > dst" + "dst > src". Поиск выполняется если одно из искомых полей (Source/Destination) пустое/any.
Строгое соответствие Чекбокс строго поиска ip-адреса.
Позволяет выполнять строгий поиск ip-адреса минуя любые его вхождения в сети. Поиск сети "net/mask" всегда выполняется строго.
Сброс IP Кнопка очистки данных Source/Destination IP.
Очищает введенные данные, возвращая поля к состоянию пусто/any/.
Горячая клавиша для вызова команды: Ctrl + c
Реверс IP Кнопка автозамены Source/Destination IP.
Заменяет местами данные полей Source и Destination IP.
Горячая клавиша для вызова команды: Ctrl + r

Форма "УЭС".

ЦОД Чекбокс "УЭС ЦОД".
Выборка для данных Управления ЦОД ЦК КСПД для парсинга конфигурационных файлов ЦОД.
ЛВС Чекбокс "УЭС ЛВС".
Выборка для данных Управления ЛВС ЦК КСПД для парсинга конфигурационных файлов ЛВС.

Форма "Фильтр по регионам".

Регионы Чекбоксы МРФ ПАО "Ростелеком".
Выборка из Макрорегионов ПАО для поиска по конкретному/-ым региону/-ам. Чекбокс "Все" делает автовыборку каждого МРФ.

Форма "Фильтр по оборудования".

Вендоры Чекбоксы вендоров сетевого оборудования".
Выборка из оборудования конкретного/-ых вендора/-ов для поиска совпадения ip-адресов/сетей. Чекбокс "Все" делает автовыборку каждого вендора.

OG Viewer Object-Group Viewer".

Сохранить на диск Экспорт вывода на компьютер.
Выполняет копирование найденной информации в файл на локальный диск ПК.
Поиск Запуск операции поиска.
Выполняет поиск совпадений/вхождений ip-адресов/сетей по выбранным фильтрам.

Object-Group Viewer.

Устройство Поле ввода названия устройства.
Заполняется стандартным названием принятом в формате ПАО "Ростелеком" ("CENG-DCAB-AS-L1C2").
Object-group Поле ввода названия Object-group.
Заполняется названием анализируемого Object-group.
IP / NetworkПоле ввода искомого ip-адреса/сети.
Выполняет поиск ip-адресов/сетей в заданном устройстве и OG. По-умолчанию - "any". Если поле пустое, будет сделан вывод всех ip-адресов/сетей OG.
Del / Del AllКнопки очистки введенных данных.
Очищает ввода конкретного поля (del) или всех полей сразу (del all).
СохранитьКнопка сохранения найденных данных OG.
Экспорт найденных данных в файл на локальный диск ПК.
Поиск Запуск операции поиска OG.
Выполняет поиск ip-адресов/сетей по заданному устройству/OG.

NetBox Viewer.

Ввод Поле ввода ip-адресов/сетей.
Заполняется ip-адресами/сетями для поиска их принадлежности к конкретной системе/PAP. Данные берутся из заполненной БД СТУ Netbox. Ограничение на разовый поиск - не более 256 адресов в сумме. Для поиска большего количества объектов разбейте количество объектов на несколько объектов/групп данных.
СохранитьКнопка сохранения найденных данных NB.
Экспорт найденных данных в файл на локальный диск ПК.
Поиск Запуск операции поиска NB.
Выполняет поиск ip-адресов/сетей в базе данных СТУ NetBox.
